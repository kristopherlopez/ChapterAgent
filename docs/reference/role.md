### Technical Excellence

- Proven hands-on experience as a data scientist or machine learning engineer, with recent successful applications of Generative AI in a business context.

- Proficiency with industry standard tools like LangChain/LangGraph, OpenAI Agents SDK and Semantic Kernel.
