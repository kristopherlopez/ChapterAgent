# Knowledge Base

Document corpus for the Q&A Agent. The ingestion pipeline flows:

```
originals/          PDF source documents (e.g., CBA Annual Report 2025)
    |
    v  extract.py (marker or pymupdf)
    |
markdown/           Extracted markdown with <!-- Page N --> annotations
    |
    v  ingest.py (chunker)
    |
chunks/             Structured JSON chunks with metadata
    |
    v  ingest.py (embedder)
    |
ChromaDB            Vector store for retrieval
```

## Folder Structure

| Folder | Contents | Git-tracked? |
|--------|----------|--------------|
| `originals/` | Source PDFs. Place the CBA Annual Report here. | No (too large) |
| `markdown/` | Extracted markdown with page annotations. Re-generated from PDFs, or hand-written synthetic content for demo. | Yes |
| `chunks/` | JSON chunks with metadata. Generated by the ingestion pipeline. | No (generated) |

## Extraction Engines

### Marker (default) — `--engine marker`

ML-based extraction using [marker-pdf](https://github.com/datalab-to/marker). Best quality for financial documents with tables, charts, and multi-column layouts.

- **Table accuracy:** 0.82 baseline, 0.91 with `--use-llm`
- **GPU:** Recommended but not required
- **Install:** `pip install marker-pdf`

With LLM enhancement (`--use-llm`), Marker uses Gemini Flash by default to post-process tables — handles cross-page table merging and complex financial table formatting.

### PyMuPDF (fallback) — `--engine pymupdf`

Rule-based text extraction using [pymupdf](https://pymupdf.readthedocs.io/). Fast, no GPU needed, but lower quality on tables and complex layouts.

- **Table accuracy:** 0.40 (not suitable for financial tables)
- **GPU:** Not needed
- **Install:** `pip install pymupdf`

Good for quick extraction of simple text-heavy PDFs, or as a fallback when Marker isn't available.

## Usage

### With a real PDF

```bash
# Place PDF in originals/
cp ~/Downloads/cba-annual-report-2024.pdf knowledge_base/originals/

# Marker (default) — best quality
cd solutions/qa-agent/src
python ingest.py

# Marker with LLM enhancement — best for financial tables
python ingest.py --use-llm

# Marker with specific LLM backend
python ingest.py --use-llm --llm-service anthropic

# PyMuPDF (fast fallback)
python ingest.py --engine pymupdf
```

### With synthetic markdown (demo mode)

The `markdown/` folder ships with 7 synthetic files covering CBA Annual Report topics. To use these without a PDF:

```bash
python ingest.py --skip-extract
```

### Just extract (no chunking/embedding)

```bash
cd solutions/qa-agent/src

# Marker
python extract.py

# Marker + LLM
python extract.py --use-llm

# PyMuPDF
python extract.py --engine pymupdf
```

## Pipeline Steps

1. **Extract** (`src/extract.py`): Reads PDFs using the chosen engine. Marker handles layout detection, table recognition, and section splitting automatically. PyMuPDF does page-by-page text extraction with heading detection. Both write markdown files with `<!-- Page N -->` annotations.

2. **Chunk** (`src/ingest.py`): Splits markdown into ~500-word chunks with 50-word overlap. Each chunk carries metadata: document name, page number, section title, source file.

3. **Save** (`src/ingest.py`): Writes `chunks/chunks.json` (full data) and `chunks/chunks_summary.json` (stats) for inspection.

4. **Embed** (`src/ingest.py`): Stores chunks in ChromaDB with cosine similarity. Uses ChromaDB's default embedding model (all-MiniLM-L6-v2). For production, swap to OpenAI `text-embedding-3-small`.
